# Jourawski Shear Recovery over an Evolving Continuous Section Field

## 1. Shear recovery as an operation on the Continuous Section Field

The sectional representation introduced above provides, at every longitudinal coordinate $z$, the complete sectional state

```math
\mathcal{S}(z).
```

Its geometric, topological, material, and sectional-participation dependencies are assumed to have already been defined as part of the Continuous Section Field and will not be repeated here. They remain embedded in every sectional quantity derived from $\mathcal{S}(z)$.

Consider the internal axial force and bending moments

```math
N(z), \qquad M_x(z), \qquad M_y(z).
```

Applying the Navier sectional model to $\mathcal{S}(z)$ gives the longitudinal normal-stress field

```math
\boxed{
\sigma_{zz}(x,y,z)
=
\mathcal{N}
\left[
\mathcal{S}(z),
N(z),
M_x(z),
M_y(z)
\right](x,y)
}
```

defined over the material regions occupied by the section at the longitudinal coordinate $z$.

From this point onward, the explicit dependence on $\mathcal{S}(z)$ can be suppressed. The field will simply be written as

```math
\sigma_{zz}(x,y,z),
```

with the understanding that its dependence on $z$ contains both:

- the longitudinal variation of the sectional actions;
- the continuous evolution of the sectional state represented by CSF.

Thus, geometry, topology, material properties, and sectional participation no longer need to appear explicitly in the subsequent equilibrium equations: their influence has already been transferred to the field $\sigma_{zz}(x,y,z)$.

The resulting conceptual sequence is

```math
\boxed{
z
\longmapsto
\mathcal{S}(z)
\longmapsto
\sigma_{zz}(x,y,z).
}
```

A classical shear-recovery relation can therefore operate directly on the stress field generated from the evolving sectional representation. Jourawski's construction provides a simple and familiar example.

---

## 2. Longitudinal equilibrium of a sectional portion

At a given longitudinal coordinate $z$, consider a portion of the cross-section denoted by

```math
\Omega^\ast(z) \subseteq \Omega(z),
```

where $\Omega(z)$ is the material domain occupied by the complete section.

The boundary separating $\Omega^\ast(z)$ from the remaining part of the section contains a cutting line, or chord,

```math
\Gamma(z).
```

A local curvilinear coordinate $s$ is introduced along this chord.

The longitudinal force carried by the portion $\Omega^\ast(z)$ is obtained by integrating the normal stress over its area:

```math
\boxed{
R^\ast(z)
=
\int_{\Omega^\ast(z)}
\sigma_{zz}(x,y,z)\,dA
}
```

where:

- $R^\ast(z)$ is the longitudinal resultant carried by the selected sectional portion;
- $dA$ is the differential area element.

Consider now an adjacent section located at

```math
z+dz.
```

The corresponding longitudinal resultant is

```math
R^\ast(z+dz).
```

For an infinitesimal longitudinal increment $dz$,

```math
R^\ast(z+dz)
=
R^\ast(z)
+
\frac{dR^\ast}{dz}\,dz.
```

The difference between the longitudinal forces acting on the two neighbouring sections must be balanced by tangential stresses transmitted across the lateral surface generated by the chord $\Gamma(z)$.

Let

```math
\tau(s,z)
```

denote the longitudinal shear stress transmitted at the point identified by the coordinate $s$ along the chord.

The corresponding shear flow is defined as

```math
\boxed{
q(z)
=
\int_{\Gamma(z)}
\tau(s,z)\,ds
}
```

where $ds$ is the differential length measured along the chord.

Longitudinal equilibrium of the differential slice gives

```math
\boxed{
q(z)
=
-
\frac{dR^\ast}{dz}
}
```

and therefore

```math
\boxed{
q(z)
=
-
\frac{d}{dz}
\left[
\int_{\Omega^\ast(z)}
\sigma_{zz}(x,y,z)\,dA
\right].
}
```

This is the Jourawski equilibrium statement written directly in terms of the longitudinal normal-stress field supplied by the sectional model.

At this stage, no assumption of homogeneous material or prismatic geometry has been introduced.

## 3. Classical prismatic and homogeneous reduction

The usual Jourawski formulation is recovered by introducing two additional assumptions:

```math
\mathcal{S}(z)=\mathcal{S}_0,
```

so that the sectional geometry is independent of $z$, and

```math
E=\text{constant},
```

so that the material is homogeneous.

For simple bending about the $x$-axis, the longitudinal normal stress then takes the classical form

```math
\sigma_{zz}(y,z)
=
-
\frac{M_x(z)}{I_x}\,y,
```

where $I_x$ is the second moment of area of the fixed section.

For a selected portion $\Omega^\ast$,

```math
R^\ast(z)
=
-
\frac{M_x(z)}{I_x}
\int_{\Omega^\ast} y\,dA.
```

Define the first moment of area of the selected portion as

```math
Q_x
=
\int_{\Omega^\ast} y\,dA.
```

Since the section is prismatic,

```math
I_x=\text{constant},
\qquad
Q_x=\text{constant along }z.
```

Therefore,

```math
\frac{dR^\ast}{dz}
=
-
\frac{Q_x}{I_x}
\frac{dM_x}{dz}.
```

Using the beam equilibrium relation

```math
\frac{dM_x}{dz}
=
T_y,
```

the shear flow becomes

```math
\boxed{
q
=
\frac{T_y Q_x}{I_x}.
}
```

If the shear stress is assumed uniform along a chord of width $b$,

```math
q=\tau b,
```

and the familiar Jourawski expression follows:

```math
\boxed{
\tau
=
\frac{T_y Q_x}{I_x b}.
}
```

The classical formula is therefore obtained only after the evolving sectional representation has been reduced to a fixed homogeneous section.

---

## 4. Return to the evolving CSF section

For the general Continuous Section Field,

```math
\mathcal{S}
=
\mathcal{S}(z),
```

and the simplifications used above are no longer required.

The normal-stress field remains

```math
\sigma_{zz}(x,y,z),
```

but its longitudinal variation now reflects the complete sectional evolution already represented by $\mathcal{S}(z)$.

Likewise, the selected sectional portion and its separating chord may vary with the longitudinal coordinate:

```math
\Omega^\ast
=
\Omega^\ast(z),
```

```math
\Gamma
=
\Gamma(z).
```

Accordingly, the shear-flow equilibrium relation retains its general form:

```math
\boxed{
q(z)
=
-
\frac{d}{dz}
\left[
\int_{\Omega^\ast(z)}
\sigma_{zz}(x,y,z)\,dA
\right].
}
```

The distinction from the classical formulation is therefore not a different equilibrium principle. The same Jourawski construction operates on quantities extracted from an evolving sectional state.

The Continuous Section Field provides the common underlying representation from which:

```math
\mathcal{S}(z)
\longrightarrow
\sigma_{zz}(x,y,z),
```

```math
\mathcal{S}(z)
\longrightarrow
\Omega^\ast(z),
```

and

```math
\mathcal{S}(z)
\longrightarrow
\Gamma(z)
```

are obtained consistently.

The classical geometrical width $b$ can therefore be regarded as a particular reduction of the more general chord $\Gamma(z)$. In the CSF representation, this chord can carry both geometric variation and the sectional material information already associated with the regions that it intersects.

This provides a direct route for extending the standard shear-recovery construction to sections that vary continuously in geometry and material participation along the longitudinal axis, without introducing separate problem-specific laws for each sectional parameter.

## 5. The Jourawski chord in the evolving section

In the classical Jourawski construction, the shear flow obtained from longitudinal equilibrium is converted into a local shear stress by introducing the width of the cutting chord.

Let

```math
\Gamma(z)
```

denote the chord separating the selected sectional portion $\Omega^\ast(z)$ from the remainder of the section at the longitudinal coordinate $z$.

A curvilinear coordinate $s$ is defined along $\Gamma(z)$, and the total geometrical length of the chord is

```math
\boxed{
b(z)
=
\int_{\Gamma(z)} ds.
}
```

For a prismatic homogeneous section, the chord geometry is fixed along the beam axis and its material properties are uniform. Under the classical assumption that the longitudinal shear stress is constant along the chord,

```math
\tau(s,z)=\tau(z),
```

the shear flow becomes

```math
q(z)
=
\int_{\Gamma}
\tau(z)\,ds
=
\tau(z)b,
```

and therefore

```math
\boxed{
\tau(z)
=
\frac{q(z)}{b}.
}
```

This is the geometrical reduction used in the standard Jourawski formula.

### 5.1 Chord extracted from the Continuous Section Field

Within CSF, the chord is not introduced as an independent geometrical parameter. It is obtained from the sectional state $\mathcal S(z)$.

Accordingly,

```math
\boxed{
\Gamma
=
\Gamma(z),
}
```

and its geometrical measure becomes

```math
\boxed{
b
=
b(z).
}
```

The variation of $b(z)$ is therefore not prescribed through an additional longitudinal law. It follows directly from the evolving geometry already represented by $\mathcal S(z)$.

More importantly, the chord may intersect different sectional regions. Since those regions and their mechanical participation are already contained in $\mathcal S(z)$, each point of the chord can also be associated with the local material information of the region to which it belongs.

The chord is therefore no longer described only by its geometrical length. At a given $z$, it carries simultaneously:

```math
\boxed{
\Gamma(z)
\quad\longrightarrow\quad
\left\{
\text{geometry along the chord},
\;
\text{material participation along the chord}
\right\}.
}
```

Both quantities originate from the same sectional representation and evolve consistently with $z$.

### 5.2 Materially non-uniform chord

Let

```math
g(s,z)
```

denote the local shear-participation quantity associated with the point identified by $s$ along the chord.

The shear stress is now allowed to vary along the chord:

```math
\tau=\tau(s,z).
```

The equilibrium definition of the shear flow remains unchanged:

```math
\boxed{
q(z)
=
\int_{\Gamma(z)}
\tau(s,z)\,ds.
}
```

To distribute the required shear flow among regions with different shear participation, the local stress may be written in the form

```math
\tau(s,z)
=
\lambda(z)\,g(s,z),
```

where $\lambda(z)$ is a scalar factor determined from the equilibrium condition.

Substituting into the shear-flow definition gives

```math
q(z)
=
\lambda(z)
\int_{\Gamma(z)}
g(s,z)\,ds,
```

and therefore

```math
\lambda(z)
=
\frac{q(z)}
{
\displaystyle
\int_{\Gamma(z)}
g(s,z)\,ds
}.
```

The resulting shear-stress distribution is

```math
\boxed{
\tau(s,z)
=
q(z)
\frac{
g(s,z)
}{
\displaystyle
\int_{\Gamma(z)}
g(\xi,z)\,d\xi
}.
}
```

Here $\xi$ is a dummy integration coordinate along the chord.

For a homogeneous chord,

```math
g(s,z)=g_0,
```

so that

```math
\int_{\Gamma(z)}
g_0\,ds
=
g_0 b(z),
```

and the expression reduces immediately to

```math
\boxed{
\tau(z)
=
\frac{q(z)}{b(z)}.
}
```

If the section is also prismatic,

```math
b(z)=b,
```

and the classical Jourawski reduction is recovered.

Thus, the standard width $b$ appears as the homogeneous and prismatic special case of a more general chord whose geometry and material participation are both obtained from the evolving sectional state $\mathcal S(z)$.
