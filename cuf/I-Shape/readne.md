# I-Shape - Prismatic and Tapered Beam Comparison


The **prismatic cross-section** is based on the geometry considered in:

> E. Carrera and G. Giunta,  
> “Refined Beam Theories Based on a Unified Formulation”,  
> *International Journal of Applied Mechanics*, 2(1), 117–143, 2010.  
> DOI: [10.1142/S1758825110000500](https://doi.org/10.1142/S1758825110000500)

Starting from this prismatic configuration, a second **tapered I-shaped beam** was generated by progressively reducing the clear web height by 80% along the beam, while keeping the flange dimensions unchanged.

The purpose of this example is to compare the CSF–CUF model with an independent three-dimensional finite-element model, starting from the prismatic I-shaped section considered in the paper and then extending the same section to a continuously tapered geometry.

## Cases

Only two configurations are considered.

### Prismatic I-shaped beam

The first case uses the constant I-shaped section geometry taken from the reference problem.

The cross-section remains unchanged along the longitudinal coordinate $x$.

### Tapered I-shaped beam

The second case starts from the same initial I-shaped section and progressively reduces the clear web height along the beam.

The taper considered here reduces the web height from

$$
a = 100\ \mathrm{mm}
$$

at the initial section to

$$
a = 20\ \mathrm{mm}
$$

at the final section.

The flange thicknesses and flange width remain unchanged.

In the CSF description, this variation is represented directly as a continuous physical section field $S(x)$. The CUF solver therefore queries the actual I-shaped section geometry at the required longitudinal positions.

The two CSF–CUF cases are available here:

[CSF–CUF I-Shape cases](https://github.com/giovanniboscu/continuous-section-field/tree/main/cuf/I-Shape)

## Independent FEM3D comparison

An independent three-dimensional finite-element model was also used for both configurations.

The comparison therefore considers:

- prismatic I-shaped CSF–CUF vs. prismatic I-shaped FEM3D;
- tapered I-shaped CSF–CUF vs. tapered I-shaped FEM3D.

Rather than comparing only a single global displacement value, the displacement evolution is examined at several points of the section perimeter.

For each selected perimeter point, the plots show the longitudinal response of the corresponding point in the two models.

The complete set of comparison plots is available here:

[FEM3D - prismatic vs. tapered comparison plots](https://github.com/giovanniboscu/continuous-section-field/tree/main/cuf/I-Shape/fem3d/prism_vs_taper)

These plots make it possible to examine both the effect of the geometric taper and the agreement between the CUF and three-dimensional descriptions along the beam length.

## Scope of this example

The example is intentionally limited to two cases: one prismatic I-shaped beam and one tapered I-shaped beam.

The prismatic configuration provides the direct connection with the geometry used in the reference paper, while the tapered configuration shows how the same I-shaped section can be extended to a continuously variable cross-section through the CSF description.

Details concerning numerical settings, mesh generation and complete reproducibility of the calculations will be documented separately.
